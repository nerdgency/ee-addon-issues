# Security policy

**Please don't report security vulnerabilities in public issues.**

Email **[security@nerdgency.ca](mailto:security@nerdgency.ca)** with:

1. What the problem is and what an attacker could do with it.
2. How to reproduce it: the steps, the requests, and the form or settings involved.
3. The Formidable, ExpressionEngine and PHP versions you tested.
4. Anything that limits it, such as a setting that has to be on or a permission the attacker needs.

We'll confirm we've received your report, keep you updated while we look into it, and release a fix as soon as we can. We're glad to credit you in the release notes, or to leave your name out if you prefer.

## Supported versions

Security fixes go into the latest Formidable 1.x release.

## Testing

Please test only against your own installations, never against a site you don't own or have permission to test.

More in the docs: [Getting help](https://nerdgency.ca/docs/formidable/getting-started/support#reporting-a-security-vulnerability).
