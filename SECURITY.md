# Security policy

This policy covers all of Nerdgency's ExpressionEngine add-ons: **Formidable** and **Autograph**.

**Please don't report security vulnerabilities in public issues.**

Email **[security@nerdgency.ca](mailto:security@nerdgency.ca)** with:

1. Which add-on, and what the problem is and what an attacker could do with it.
2. How to reproduce it: the steps, the requests, and the form, field or settings involved.
3. The add-on, ExpressionEngine and PHP versions you tested.
4. Anything that limits it, such as a setting that has to be on or a permission the attacker needs.

We'll confirm we've received your report, keep you updated while we look into it, and release a fix as soon as we can. We're glad to credit you in the release notes, or to leave your name out if you prefer.

## Supported versions

| Add-on | Security fixes go into |
| --- | --- |
| Formidable | The latest 1.x release |
| Autograph | The latest release of the current major version |

## Testing

Please test only against your own installations, never against a site you don't own or have permission to test.

More in the docs: [Formidable](https://nerdgency.ca/docs/formidable/getting-started/support#reporting-a-security-vulnerability) · [Autograph](https://nerdgency.ca/docs/autograph/getting-started/support#reporting-a-security-vulnerability).
